Add optional TTL support to LRUCache. The constructor should accept an optional options object with a default TTL in ms (`new LRUCache(cap, { ttl: 1000 })`), and `set(key, value, ttlMs?)` can override it per entry. No TTL means the entry never expires. Expired entries must behave as if they were never there: `get`/`has` return undefined/false, they don't count in `size` and don't show up in `keys()`. When the cache is full, expired entries should be dropped before evicting any live one. Add a `now?: () => number` option (defaults to Date.now) so it's testable.
